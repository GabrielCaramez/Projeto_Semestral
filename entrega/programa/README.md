# ReVeste — MVP

## Como executar

Abra o arquivo `index.html` em um navegador. Não é necessário instalar
servidor ou dependências.

## Funcionalidades implementadas

- Consulta e filtros do catálogo;
- Carrinho com peças únicas;
- Finalização de pedido com Pix simulado;
- Acompanhamento de pedidos;
- Cadastro e ativação/desativação de produtos;
- Consulta de fornecedores;
- Abertura de chamados de atendimento;
- Persistência local com `localStorage`.

Este é um protótipo acadêmico do MVP. A integração real com um gateway Pix,
autenticação, banco de dados e armazenamento de imagens deve ser adicionada em
uma etapa de produção.
